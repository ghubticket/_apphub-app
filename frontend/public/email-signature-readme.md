# Assinatura de Email Vicente

Assinatura de email profissional e elegante para a marca Vicente, compatível com todos os principais clientes de email.

## 📋 Características

- ✅ **Design Flat e Moderno** - Baseado no layout do site Vicente
- ✅ **100% Compatível** - Usa apenas tabelas HTML básicas
- ✅ **Responsivo** - Funciona em desktop e mobile
- ✅ **Todas as Plataformas** - Gmail, Outlook, Apple Mail, Yahoo, etc.

## 🎨 Design

- **Cores Principais:**
  - Laranja: `#f97316` (cor de destaque)
  - Preto: `#1a1a1d` (textos principais)
  - Cinza: `#4c4c55`, `#7d796c`, `#9ca3af` (textos secundários)
  - Branco: `#ffffff` (fundo)

- **Tipografia:**
  - Fontes do sistema: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto`

## 📁 Arquivos

1. **`email-signature.html`** - Versão completa com estrutura HTML completa
2. **`email-signature-simple.html`** - Versão simplificada para copiar/colar diretamente no cliente de email

## 🚀 Como Usar

### Opção 1: Versão Simplificada (Recomendado)

1. Abra o arquivo `email-signature-simple.html`
2. Substitua `[Seu Nome]` pelo seu nome
3. Substitua `[Seu Cargo]` pelo seu cargo
4. Copie todo o conteúdo HTML
5. Cole no seu cliente de email (Gmail, Outlook, etc.)

### Opção 2: Versão Completa

1. Abra o arquivo `email-signature.html` em um navegador
2. Copie o conteúdo visualizado
3. Cole no seu cliente de email
